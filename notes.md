## Docker
- Container Creating technology
- It is a tool to create containers and manage containers
- **Container is a package of code and dependencies**

## Docker Tools:
- Docker Engine
- Docker Desktop
- Docker Hub
- Docker Compose

## Commands:
- docker build . : To build the image
- docker build -p port:port: To build the container based on the image and publish on the port
- docker ps: To list the running container
- docker stop cont_name: To stop the container
